# Fiscale — Méthodologie fiscale

Landing page responsive en français présentant un séminaire de méthodologie fiscale en 7 séquences.

## Lancer en local

Le projet est statique et ne nécessite aucune dépendance :

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Puis ouvrir `http://localhost:4173`.

## Contenu

- `index.html` — structure et contenu du parcours
- `styles.css` — direction artistique, illustrations et responsive design
- `script.js` — navigation mobile, accordéons, rail de progression et retour en haut
